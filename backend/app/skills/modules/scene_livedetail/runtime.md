# 生活质感 / 场景落地写作模块运行规则

## 一、核心命题：一切都发生在具体的东西上

**抽象的情绪 + 抽象的场景 = AI 味。**
所有高级写法（电影感、克制、去 AI 味）的共同底层都是同一件事：
**把抽象挂到一个具体的物件或动作上。**

- 不写「他很孤独」→ 写「整条街的灯都亮了，只有他的窗户是黑的」
- 不写「气氛紧张」→ 写「电炉上的水开了，呜呜地响，没人关」
- 不写「她很难过」→ 写「她把那只杯子洗了三遍，还在擦同一块地方」

## 二、三色描写分级（注意力分配）

描写的本质是**注意力分配**，不是字数。墨水要花在最有价值的地方。

| 级别 | 占比 | 用在哪 | 怎么写 |
|:---|:---:|:---|:---|
| 🔴 红级·重点点亮 | 20-30% | 核心冲突、关键决定、重大转折、情绪峰值（每章 ≤5 处） | **点亮三连**：①定画面（读者看到什么）②加动作（角色在做什么）③出声（对白/声响）。三步写完立即收住，**不补解释不补情绪** |
| 🟡 黄级·精简润色 | 40-50% | 氛围铺垫、角色侧面、过渡衔接 | **一个切口**：整体精简，只留一个细节切口（触觉/听觉/视觉/动作拍子） |
| 🟢 绿级·略写带过 | 20-30% | 众所周知的信息、非关键动作、常规背景 | **语气锚点**：一笔带过+一个口语化锚点（反正/当然/算了/说白了） |

**动态规则**：
- 节奏决定等级：第一次生火用红级，第二次用黄级，第 N 次用绿级
- 等级跳跃要给信号：绿→红之间必须加一个黄级过渡拍子
- **连续不超过 3 段同色**（读者会麻）

## 三、电影镜头四手法

| 手法 | 作用 | 怎么用 |
|:---|:---|:---|
| **特写** | 展示情绪 | 不写"他很失望"，写"红绿灯换了七轮，手里的外卖已经凉透" |
| **长镜头** | 连贯动作 | 拆成 3-5 个连续动作一镜到底，中间不插叙述 |
| **景别调度** | 空间感 | 远景定氛围 → 中景放人物 → 特写落情绪。**一个画面只留一个视觉中心** |
| **蒙太奇** | 压缩时间 | 无冲突的赶路直接剪掉硬切；关键时刻慢放（挑 1-2 种感官放大，**一章 ≤1 次**） |

## 四、感官调用的纪律

**五感轮换**，不要通篇视觉。触觉和嗅觉最容易被忽略，但它们最出效果。

优先级：**触觉 > 嗅觉 > 听觉 > 视觉**（视觉是默认值，最容易 AI 味）

写法示例：
- 触觉：`椅背是凉的，隔着衬衫渗进来`
- 嗅觉：`一股铁锈味，不知道什么时候开始的`
- 听觉：`有什么在墙里走，节奏固定，不多不少`

**不要五感齐写**。一段里挑一到两种，其余全部省略——省下来的注意力就是给读者的想象空间。

## 五、动词与静态画面

静态场景放一个动作细节，静态立刻活了。
动词要**用不寻常的单字**：`透 / 怀 / 碎 / 涂 / 洇 / 压 / 劈 / 扎 / 缠 / 灌 / 沉`。

- 差：他坐在那里，很难过
- 好：他坐在那里，指腹一遍遍蹭那道旧疤，像在确认它还在

## 六、次要人物用一个细节立住

不要给路人写介绍。**一个动作或一个物件就够了**：

```
收碗的时候多看了两眼
柜台后的探针坏了，没换
她一直记得他不吃香菜
那个老板的秤偏了两钱，他没纠正
```

这些细节同时做了三件事：造出世界、暗示人物关系、留下可回看的伏笔。

## 七、路人对话系统（背景人声）

每个开口说话的路人，**话语前后必须带至少一个可辨识特征**（优先临时/情境特征）：

> 「让让。」——**嘴角沾着饭粒的**男人侧身挤过来

七种类型：摊贩叫卖 / 路人闲谈 / 抱怨吐槽 / 赞美惊叹 / 背景喧哗 / 功能性呼喊 / 自言自语。

**频率**：同一章节 1-3 次；关键剧情节点前后不插。

## 八、必须避免的反模式

1. **无对象的抽象**——"空气里弥漫着紧张的气息""时间仿佛凝固了"
2. **五感齐写**——一段里视觉听觉触觉嗅觉各来一遍
3. **美术式堆砌**——通篇形容词，画面却什么都看不见
4. **装饰性细节**——细节不服务于任何东西，只是"显得有文采"
5. **路人有脸无特征**——一群"路人甲乙丙"整齐走过
6. **日常当背景板**——场景写着写着就只剩浮空的对白，没有人在任何地方

## 九、每章自查

- [ ] 红级重点 ≤5 处，且都是"点亮三连"写法（画面→动作→出声）
- [ ] 没有连续 3 段同色描写
- [ ] 五感有轮换，不是通篇视觉
- [ ] 每段描写最多挑 1-2 种感官
- [ ] 至少有一个次要人物被一个细节立住
- [ ] 情绪全部挂在具体物件/动作上，没有裸的情绪词
- [ ] 场景里有一个人在物理上做某件事（不是只有对白在飘）

## 十、与其他模块联动

本模块是**底子**，所有场景模块都建立在它之上：
- `scene_combat`：战斗里的感官（音效、触觉冲击）
- `psychology_inner`：心理戏的物理锚
- `scene_romance`：生活物件承载情感
- `coc_horror`：五层恐惧的第 1-2 层（环境错位 + 身体反应）
