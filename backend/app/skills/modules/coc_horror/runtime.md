# 克苏鲁恐怖写作模块运行规则

## 一、核心美学：不可名状不是形容词堆砌

克苏鲁恐怖的恐惧源头不是"怪物长得吓人"，而是"认知本身开始崩塌"。

三条铁律：
1. **神不出场，神不说话**。任何古神、外神、旧日支配者都不能直接现身、不能直接对话、不能有台词。只能通过痕迹、余波、梦境、他人转述、后遗症间接呈现。
2. **恐惧来自"我开始理解错了"**。主角以为的"事实"一层层剥落，露出来的不是答案，而是更深的"我连问题都问错了"。
3. **身体感受先于理性判断**。不要写"他感到一阵恐惧"，写"后颈的汗毛竖起来之前，他的手已经在抖"；不要写"那东西很恶心"，写"舌根涌出一股铁锈味，他不知道自己什么时候咬破了舌头"。

## 二、什么时候必须调用

- 写 Day2-Day7 场境内的探索/遭遇/仪式/发现场景
- 写遗物、残页、讣告相关段落
- 写侵蚀度上升、理智受损段落
- 审稿时发现文本出现"克苏鲁味不足"（形容词堆砌、神直接出场、恐怖靠怪物描写）
- 写任何涉及"能力使用"的段落（需联动 obsession_cost）

## 三、五层恐惧叠加法（从外到内）

写恐怖场景时按这个顺序铺，不要跳层：

### 第 1 层：环境错位（外部信号）
- 不该有的声音/气味/温度/光线
- 空间几何出问题（走廊比记忆里长、房间角度不对、楼梯多了一阶）
- 时间感错乱（表停了、天没黑但已经过了四小时、手机电量异常）
- **写法要具体**：不要"阴森恐怖"，要"走廊尽头的灯泡频率和他记忆里不一样，闪的间隙里他好像看到了什么，但眨眼看时墙皮还是那块墙皮"

### 第 2 层：身体反应（生理信号）
- 主角身体先于大脑反应：手抖、冷汗、耳鸣、嘴里发苦、视野边缘发暗
- 感官错位：听见不存在的声音、闻到不属于这里的味道、皮肤感觉到不该有的触感
- 不要写"他吓得浑身发抖"，要写"他攥着手机的手太用力，指节发白，指甲掐进掌心的痛感让他确认自己还能感觉到疼"

### 第 3 层：认知裂隙（心理信号）
- 发现"我之前理解的这件事完全不对"
- 线索对上之后不是"原来如此"，是"原来我连谜面都看错了"
- 记忆开始不可靠：我刚才是不是来过这里？那个人刚才是不是说了不同的话？
- 示例："他翻开残页的第三张，上面是他自己的笔迹，但他不记得写过。"

### 第 4 层：存在性不安（哲学信号）
- 我是谁？我还是我吗？
- 这件事如果是真的，那我之前以为的"正常世界"是什么？
- 我正在使用的能力到底是"我"在使用，还是"它"在通过我使用？
- 点到即止，不要展开长篇内心独白，用动作/物件/一句话刺破

### 第 5 层：余波（代价/后遗症）
- 恐怖场景结束之后，恐惧不会立刻消失
- 身体留下痕迹：伤口、淤青、体温异常、持续性的某个感官错位
- 心理留下裂缝：开始回避某个话题、某个动作会触发闪回、梦里出现片段
- 这一层必须写——没有余波的恐怖是廉价跳吓

## 四、神不出场的五种"在场"写法

既然神不能直接出现，用这些方式让读者感受到"它在"：

1. **痕迹法**：写它经过的痕迹。墙上的黏液、温度异常的区域、死去动物的姿态、空气中某种不属于任何已知物质的气味。
2. **代理人法**：通过被影响的人/物呈现。狂信徒的祷词（但祷词不能直接解释神是什么）、被附身者的异常行为、以不可能方式损坏的物件。
3. **梦境/幻觉法**：模糊、断裂、逻辑跳跃的梦境片段。醒来后只记得情绪和一个画面，具体内容在睁眼的瞬间开始消散。
4. **物理法则偏移法**：小范围的物理异常。重力方向轻微偏转、水流方向不对、声音传播速度变化、影子方向和光源对不上。要写得非常克制——主角自己都不确定是不是看错了。
5. **能力反应法**：主角身上的"能力"对某个方向/物件/人名产生反应。烫、冷、震、拉扯感——但能力本身不解释为什么。

## 五、SAN 值（侵蚀度）写法对照表

| 侵蚀区间 | 写作表现 |
|---------|---------|
| 0-20 | 轻微违和感。"可能是我想多了。" 读者比主角更不安。 |
| 20-40 | 无法忽视的异常。开始做噩梦，感官偶有错位，身边人察觉主角"不对劲"。 |
| 40-60 | 现实感松动。会出现短暂的幻觉或记忆断层，对身边人的信任感下降，开始依赖能力（代价也在加重）。 |
| 60-80 | 边界模糊。分不清哪段是梦境哪段是现实，能看见普通人看不见的东西，身体出现无法解释的标记/疼痛。 |
| 80-95 | 半只脚在那边。逻辑思维还在但情感疏离，能直接"读"到某些信息，活人看着他会觉得不对劲。 |
| 95+ | 临近消失。最后一点"我是唐迟"的锚点在松动，必须靠强烈的世俗执念（对某人的承诺、某个未完成的事）拽回来。 |

**重要**：侵蚀度上升要有迹可循，不是突然跳变。每次大的恐怖场景后明确写一条新出现的后遗症，在后续日常场景里偶尔提及（不要重复强调，偶尔一笔带过效果更好）。

## 六、必须避免的反模式

1. **形容词堆砌**："不可名状的恐怖""无法形容的恶心""毛骨悚然的氛围"——删掉这些，写具体的感官细节。
2. **神直接登场/开口**：任何形式的"我看到了它""它对我说"都违规，零容忍。
3. **主角一次性看穿真相**：克苏鲁世界里真相是洋葱，剥一层哭一层，永远剥不到芯。
4. **用"疯狂"当装饰**：疯狂不是酷的标签，是有具体表现和代价的。参考侵蚀度表。
5. **大段设定说明**：不写"这个古神是XXX，它在XXXX年来到地球"。所有世界观信息通过残页、对话、发现的文献碎片逐步透露，碎片之间可能矛盾，永远不要拼成完整真相。
6. **靠怪物外形吓人**：描写怪物重点不是"长什么样"，而是"看到它之后主角的感知/认知发生了什么变化"。
7. **主角无代价脱险**：从恐怖场景走出来必须留下点什么——记忆、身体部位、某种能力的代价、对某个人的信任、一块皮肤的感觉。

## 七、与其他模块联动

- **obsession_cost**：任何能力使用段落必须同时触发代价描写
- **interlude_relief**：场境内的恐怖密度高，幕间要透气但不能断根（留暗刺）
- **infinite_loop_unit**：七日节奏内，恐怖密度随 Day 数字递增，Day1 是违和感，Day5-7 是认知崩塌
- **chapter_ending**：恐怖场景的章末不要收在"吓完就完"，要收在"主角带着新的裂缝/新的认知/新的代价进入下一场"
