# 战斗场景写作模块运行规则

## 一、核心美学：战斗是资源结算，不是动作播报

战斗的读者快感不来自"打得激烈"，来自**读者能算清每一击的得失**。
读者心里要有这样一本账：谁占优、为什么占优、什么时候会被翻盘、翻盘需要付出什么。

三条铁律：
1. **一招一结果**。每个动作必须落到一个可观察的变化上：位置变了、东西掉了、谁流了血、谁失去了平衡。禁止"打了半天没进展"。
2. **禁止报招式名**。不写"使出一记擒拿""施展罗汉拳"，写"左手扣住对方腕子往外一别"。
3. **禁止战后解说原理**。打完就收，读者不写，叙述者更不该当场点评刚才那招多妙。

## 二、战斗四拍（每个有效动作）

```
动作（动词精准的短句）→ 音效（让读者听见）→ 结果（状态变化）→ 反应（对手或旁人的即时反馈）
```

示例：右拳抢到颧骨上，骨头闷响一声，那人的头往旁边偏过去，血从鼻孔里淌到嘴角。

四拍可以合并成一句，但**四要素缺一不可**。最常丢的是第四拍——只写动作不写反应，战斗就成了两个人的默片。

## 三、节奏三拍（一场战斗的配额分配）

| 阶段 | 篇幅占比 | 内容 |
|:---|:---:|:---|
| 消耗 | 40% | 试探、周旋、读对手、磨血。双方都不下死手，读者在积累信息。 |
| 爆发 | 30% | 找到破绽、一方全力输出。节奏陡升，描写密度翻倍。 |
| 绝杀 | 30% | 收尾一击 + 结果宣告。短促，不拖。 |

铁律：**不要一上来就爆发**。跳过消耗直接爆发，读者还没建立对双方能力的认知，就已经被告知谁强谁弱，除了"哇好厉害"之外没有任何判断——那不是爽，是空转。

## 四、动词速查（禁用"打""踢"这类过泛动词）

| 部位 | 可用动词 |
|:---|:---|
| 拳 | 冲、击、贯、捣、戳、砸、抡、封 |
| 腿 | 扫、摆、抽、鞭、蹬、踹、别、绊 |
| 刀剑 | 刺、扎、劈、砍、斩、抹、挑、卸 |
| 身法 | 压、欺、抢、拧、别、扣、卡、贴 |
| 音效 | 噗、嘭、咚、铛、锵、嗤、喀、闷响 |

## 五、场面调度（多人场景）

多人混战**按职责分镜头**推进，不要把所有人的动作堆在同一句里：
先给压制方的动作 → 给防守方的反应 → 给第三人的介入 → 再回到压制方。

**死亡顺序用"预期—打破"**：
先让读者以为某人要死（他被压制、他受伤、他落在圈外），
再在下一个动作里让他活下来，但付出代价或欠下人情。
每一次"打破预期"都要在场景内留下痕迹。

## 六、信息差是战斗的核心引擎

读者应该知道**比场上角色多一点或少一点**：
- 比主角多：读者看见威胁从哪来，主角还没察觉 → 悬念
- 比主角少：读者和主角一起发现"原来如此" → 反转

两者都行，**最忌讳的是读者全知而主角不知且无人提示**——那不是悬念，那是作者在藏。

## 七、必须避免的反模式

1. **「顿了顿」「淡淡道」「冷声道」「沉声道」「画面一转」「镜头」**——全部禁用。战斗中没有旁白配音。
2. **破折号、省略号**在战斗段落里禁用（各有专门用途，见去 AI 味模块）。
3. **「顿时/霎时/就在这时」全章合计 ≤1 次**。战斗靠动词推进，不靠时间副词推进。
4. **「一丝/一缕/一抹」全章合计 ≤1 次**。量化修饰在战斗里一律换成具体动作。
5. **围观众观写"众人大惊失色"**——要写具体的细微反应：谁退了半步、谁的手停在半空、谁咽了口唾沫。抽象反应等于没写。
6. **主角无代价取胜**。赢必须留下东西：受伤、暴露、消耗掉某个底牌、或欠下人情。

## 八、每场战斗写完的自查

- [ ] 每一击都有结果变化（不是打空气）
- [ ] 没有一处报招式名
- [ ] 有消耗段，不是直接爆发
- [ ] 动词具体，不是"打/踢/攻击"
- [ ] 围观/对手有具体反应，不是"大惊失色"
- [ ] 赢了，但付出了一样东西
- [ ] 没有禁用副词（顿了顿/顿时/霎时）撑场

## 九、与其他模块联动

- **psychology_inner**：主角的战斗决策从哪来（判断→决心），本模块管执行层
- **dialogue**：战斗中的对话短到只剩指令和挑衅
- **obsession_cost**：每次动用非常规手段必触发代价描写
- **chapter_ending**：战斗章末收在代价或新威胁，不收在"打赢了"
