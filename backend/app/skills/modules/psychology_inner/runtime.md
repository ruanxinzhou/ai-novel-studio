# 心理 / 内心戏写作模块运行规则

## 一、核心禁令：叙述者不许替角色下结论

**心理戏最容易写坏的方式，是作者跳出来替角色解释。**

禁用词表（出现即改）：
> 心里一紧 / 瞳孔微缩 / 五味杂陈 / 心头一颤 / 血液都凝固了 /
> 他知道 / 他明白 / 他意识到 / 内心充满了 / 一种莫名的情绪涌上心头

这不是"心理描写不够好"，是**心理描写被偷懒替代了**——模型不会写细腻的内心，就用这些成语假装写过了。

## 二、正确的做法：情绪 → 身体 → 动作

情绪永远由三层承载，**从上到下写，不要直接写情绪本身**：

```
第一层 生理反应（身体先于意识）
  手里的杯子磕在桌沿 / 后颈的汗毛先立起来 / 呼吸卡在喉咙口

第二层 认知中断（思维被打断，不是想通了）
  他准备好的那句话说出口时，发现词不对 / 数字算到第三遍还是不成立

第三层 行为偏移（做出一个和处境不一致的小动作）
  把已经收好的东西又拿出来摆了一遍 / 明知道该走，多站了三秒
```

**反例**（模型爱写）：他感到一阵愤怒和不甘。
**正例**（本模块要写）：他把烟盒捏扁了，又捏了一下，捏第三下的时候才发现里面早空了。

## 三、复杂情绪必须拆开，不能合并

角色同时有多种感受时，**不能写成"五味杂陈"**，必须拆成四类分别给动作：

| 类型 | 含义 | 表现方式 |
|:---|:---|:---|
| 显性情绪 | 角色自己承认的 | 可以说出口，可以写进决定 |
| 隐性情绪 | 不愿承认的 | 只从破绽漏出（手停半空、话说到一半咽回去） |
| 矛盾情绪 | 两种相反情绪同时存在 | 体现在**互相抵消的动作**上（手伸出去又收回来） |
| 未命名情绪 | 说不清的 | 只通过环境或一个物件承载，不给词 |

每种情绪**只用 1-2 个具体动作表达**，绝不给情绪命名。

## 四、情绪滞后性（最容易漏的一条）

**角色在剧烈情绪之后，不能立刻恢复理性说话。**

- 被打了一巴掌，不会立刻冷静分析局势
- 刚听到死讯，不会马上条理清楚地复述经过
- 刚哭完，不会马上切换成安慰别人的语气

必须写出**回落过程**：情绪峰值 → 生理余波（喘不上气 / 手抖 / 声音变调）→ 强行压回去 → 压回去之后的行为变形（说错话、答非所问、重复同一句）。

**和解必须有代价**：一句"对不起"翻篇是假的。真实的和解要有让步、认错、或暴露脆弱中的一样。

## 五、内心独白的三条纪律

1. **视角锁死**：只有当前视角角色的内心能写。非视角人物的心理只能转成**可观察的外在**（他的表情、他的手、他突然换了话题）。
2. **不要用内心独白解释读者已经知道的事**。读者已经知道他是去赴死，就别再写"他知道自己此去多半凶险"。
3. **吐槽的额度**：内心戏可以带自嘲和吐槽，但一句为主两句为上限。**情绪顶点不吐槽**——哭戏、告白、真相揭晓、相认的核心段落必须让路。

## 六、心理场景的外部锚

纯内心戏超过两屏就会憋闷。**每一段内心戏都要外挂一个物理锚**：
- 手上的动作（在做什么）
- 周围的声音（环境音）
- 身体的生理状态（哪里疼、哪里麻）
- 时间压力（几点、多久没动）

写法：先给物理锚 → 内心动 → 再回到物理锚。
读者需要一个东西"抓"着，才能跟着角色一起沉下去。

## 七、认知类心理戏：反转必须打在"他以为"上

当本章包含认知反转时，心理戏的落点是**落差**，不是"发现真相"：

```
以为：他原以为 X 是 Y 做的
转折：证据指向 Z
落点：那个 Z 恰好是他自己信任过的人 / 那个 Y 是他一直在保护的人
```

关键在**落差要打在他有情感投入的地方**。真相本身不吓人，"我信任的人做的"才吓人。

## 八、必须避免的反模式

1. **成语的直接情绪**（心头一颤、五味杂陈、内心涌起）——全部换成生理+动作。
2. **叙述者读心**（他明白 / 他意识到 / 他知道）——删掉，让读者自己得出结论。
3. **自我分析式独白**（我为什么要这么做？我很清楚我在逃避）——真实的人不给自己做心理诊断，他只是做了。
4. **情绪瞬间归零**——峰值后必须有回落过程。
5. **长篇自我剖析**——超过三屏的心理独白必须插入物理锚打断。
6. **给情绪命名**（他感到紧张 / 她很愤怒）——情绪没有名字，只有行为。

## 九、与其他模块联动

- **dialogue**：说了出口的话和没说出口的话同样重要，本模块产出后者，对白模块管前者
- **scene_combat**：战斗中的心理活动只写决策瞬间（判断→决心），不写犹豫反复
- **coc_horror**：恐惧走五层叠加，本模块管的是主角**意识到**"我理解错了"的那一刻
- **anti_ai_voice**：本章最重要的 P0 去味目标就是心理段的成语堆砌
