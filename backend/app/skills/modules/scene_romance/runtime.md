# 情感 / 恋爱场景写作模块运行规则

## 一、核心禁令：情绪不许直接说出来

**这是整个模块唯一但最重要的规则。**

禁用（直接表达情绪）：
> 我很难过 / 我很孤独 / 我很委屈 / 我害怕失去你 / 我很爱你 /
> 我对你失望了 / 我想你 / 你知道吗我一直在等

角色不说这些。角色说的是**别的**，读者从别的里面读出这个。

低级版：「我舍不得你。」
正确写法：
```
「几点的车？」
「八点。」
「哦。」
「还有什么？」
「没了。」
```

真正的情绪藏在**问什么**里，不在答什么里。

**改写公式：情绪结论 → 可观察行为**。

## 二、潜台词：每句重要对白都要有第二层

写任何一句重要台词前，先问两层：
- **表层**：人物正在说什么？
- **深层**：人物真正想表达什么？

例：
| 表层 | 深层 |
|:---|:---|
| 「今天回来挺早。」 | 「你是不是特意回来见我？」 |
| 「随便你。」 | 「我很在意，但我不想求你。」 |
| 「没事。」 | 「有事，但我不想再解释。」 |

只优化语言而不找"人物没有说出口的需求"，就是在做文字游戏，不是写作。

## 三、对白三层结构（重要场景必建）

```
第一层【表面事件】具体的现实事务：吃饭、工作、天气、收拾东西
第二层【关系变化】  疏离 / 试探 / 依赖 / 防备 / 想靠近
第三层【核心情绪】  隐藏的爱、遗憾、失望、孤独、不甘、和解
```

**第三层永远不能直接说**，让读者自己理解。
三层要**分离**：不要在第一层事务里夹杂第三层的抒情，那会显得人物在表演。

## 四、用生活细节承载情绪

**大情绪放进小事情。**

禁止人物持续讨论爱、孤独、梦想、人生、遗憾、救赎——真实的人不那样说话，读者也不那样听。
优先使用：吃饭、买东西、回家、做饭、等车、天气、工作、收拾房间、借东西、关灯。

反面：「我希望你留下。」
正确写法：
```
「冰箱里的菜你吃掉。」
「我明天走。」
「知道。」
「那菜怎么办？」
```

## 五、冰山三式（每段对话至少含一种）

1. **说反话**：「你走吧。」（其实想留）
2. **答非所问**：「你怕吗？」「……今晚月亮真圆。」
3. **沉默代替**：「你爱我吗？」她把他的手握紧了一点

## 六、适度制造未完成感

现实交流不是每句话都有答案。允许：说一半停下、改口、咽回去、转移话题、明明想问却问别的。

低级：「你是不是不想见我？」
正确写法：
```
「最近很忙？」
「还好。」
「哦。」
「……」
「那挺好的。」
```

**注意**：不能所有人物都故意神秘。留白必须服务人物，不是所有人的通用腔调。

## 七、人物语言必须区别化

遮住名字能认出是谁，才算写活了。四个判断维度：

| 维度 | 影响 |
|:---|:---|
| **年龄** | 年轻人更直接、碎片化；成年人更克制、习惯隐藏；老人更多经验化表达 |
| **性格** | 强势者少解释多决定；敏感者绕开重点；温柔者通过照顾表达；冷漠者减少情绪词 |
| **身份** | 职业、阶层、成长环境决定用词、语速、禁忌话题 |
| **关系** | 面对父母退让、面对爱人暴露脆弱、面对敌人锋利、面对陌生人保持距离 |

**同一人物对不同对象说话必须不同**。对爱人说的话不能直接对敌人说——那是同一个人在两种场合的语域切换。

## 八、核心情绪锚点（人物设计的底层）

角色不能只贴表面标签。必须先确定一个**终身不变的核心情绪锚点**——这个人一生真正渴望什么。

锚点 ≠ 表面身份：
- 不是"他是鬼"，核心是**寻找归宿**
- 不是"她在复仇"，核心是**夺回被夺走的人生**

剧情不是改变角色，剧情是在不断考验这个锚点。每次冲突，都是问他：你这个锚点还在吗？

## 九、作者腔对白全清单（出现即删）

- **心理解释**：「我虽然表面坚强，但内心很痛苦」
- **剧情说明**：「你知道当年发生的一切」
- **关系说明**：「我们认识这么多年了」
- **人生哲理**：「人生就是有得有失」
- **鸡汤安慰**：「你一定要好好生活」
- **金句堆砌**：任何一句听起来像摘抄的话

对白必须像真实人在说话。

## 十、每场情感戏的自查（五问）

- [ ] Q1 表面在聊什么？（必须具体，如"讨论谁去机场接人"，不是"聊感情"）
- [ ] Q2 真正想得到什么？（想被挽留/想确认在乎/想被道歉/想保持尊严/想拒绝靠近）
- [ ] Q3 为什么不直接说？（阻碍：自尊、怕被拒、不习惯表达、不信任、怕失控）
- [ ] Q4 有没有生活事件承载？（把"我想你"变成"你房间钥匙还留着"）
- [ ] Q5 删掉这句话还能看懂吗？**能看懂就删**

## 十一、与其他模块联动

- **psychology_inner**：情感戏的内心层走"生理→认知→行为"三层，不直接写情绪名
- **dialogue**：对白的潜台词机制本模块更严格，情感场景下以本模块为准
- **character_consistency**：核心情绪锚点写入角色档案，避免跨章漂移
- **chapter_ending**：情感章末收在未说完的话或一个小动作上，不收在表白
